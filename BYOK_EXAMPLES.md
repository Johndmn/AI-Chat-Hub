## Пример 1: Первый запуск и настройка

### Шаг 1: Запуск приложения

```bash

```

### Шаг 2: Ввод API ключа

1. Откройте expander **"🔑 Настройки API"** в левой панели
2. Вставьте ваш API ключ в поле (например: `sk-proj-abcd1234...`)
3. Нажмите **"💾 Сохранить ключ"**
4. Увидите: **"✅ Ключ сохранён. Можно работать."**

### Шаг 3: Первый запрос

Введите в поле ввода:


Модель ответит понятным объяснением с учётом текущей температуры.

## Пример 7: Анализ и исправление кода

### Задача: Найти баг в коде

**Настройки:**

- Модель: `gpt-4o-mini`
- Температура: `0.3`

**Запрос:**

```
Найди ошибку в этом коде:

def calculate_average(numbers):
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)

# Тест
result = calculate_average([])
print(result)
```

**Ответ модели:**

```
Проблема: division by zero при пустом списке.

Исправленный код:

def calculate_average(numbers):
    if not numbers:
        return 0
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)
```

## Пример 8: Перевод и объяснение

### Задача: Перевести и объяснить технический текст

**Настройки:**

- Модель: `gpt-4o-mini`
- Температура: `0.5`

**Запрос:**

```
Переведи на русский и объясни простыми словами:

"A hash table is a data structure that implements an associative array,
a structure that can map keys to values. It uses a hash function to
compute an index into an array of buckets or slots, from which the
desired value can be found."
```

**Ответ модели:**

```
Перевод:
"Хеш-таблица — это структура данных, которая реализует ассоциативный
массив, структуру, способную сопоставлять ключи значениям. Она
использует хеш-функцию для вычисления индекса в массиве сегментов,
из которого можно найти нужное значение."

Простыми словами:
Представь телефонную книгу, где вместо перелистывания всех страниц,
ты используешь специальную формулу (хеш-функцию), которая сразу
говорит, на какой странице искать нужный номер. Это делает поиск
очень быстрым!
```

## Советы по эффективному использованию

### ✅ Хорошие практики

1. **Будьте конкретны:**

   - ❌ "Расскажи о Python"
   - ✅ "Объясни разницу между списком и кортежем в Python с примерами"

2. **Разбивайте сложные задачи:**

   - ❌ "Создай полноценный интернет-магазин"
   - ✅ "Шаг 1: Создай структуру базы данных для интернет-магазина"

3. **Используйте контекст:**

   - Модель помнит предыдущие сообщения в чате
   - Можно ссылаться на ранее упомянутое: "Улучши этот код"

4. **Экспериментируйте с температурой:**
   - Точность: 0.2-0.4
   - Баланс: 0.5-0.7
   - Креативность: 0.8-1.0

### ❌ Чего избегать

1. **Не отправляйте конфиденциальные данные:**

   - Пароли, API ключи, персональные данные
   - Коммерческую тайну

2. **Не полагайтесь на 100% точность:**

   - Всегда проверяйте фактическую информацию
   - Особенно в медицине, юриспруденции, финансах

3. **Не создавайте слишком длинные диалоги:**
   - Каждое сообщение в истории = дополнительные токены
   - Создавайте новый чат для новой темы
