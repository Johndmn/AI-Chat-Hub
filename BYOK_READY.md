## 🔑 Где взять API ключ?

### Шаг 1: Перейдите на OpenAI

https://platform.openai.com/api-keys

### Шаг 2: Войдите в аккаунт

- Если нет аккаунта - создайте (бесплатно)

### Шаг 3: Создайте ключ

1. Нажмите **"Create new secret key"**
2. Дайте ключу название (например, "AI Tutor")
3. Скопируйте ключ (он начинается с `sk-`)

### Шаг 4: Вставьте в приложение

1. Вернитесь в браузер с приложением
2. Вставьте ключ в поле
3. Нажмите "💾 Сохранить и начать работу"

## 🔐 Безопасность

### ✅ Ваш ключ защищён

- **Хранится только в памяти** - не записывается на диск
- **Скрыт при вводе** - символы отображаются как `•••`
- **Удаляется автоматически** - при закрытии браузера
- **Можно очистить вручную** - кнопка "🗑️ Очистить ключ"

### ⚠️ Важно помнить

1. **При каждом запуске нужно вводить ключ заново**

   - Это сделано для безопасности
   - Ключ не сохраняется между сессиями

2. **При обновлении страницы (F5) ключ теряется**

   - Нужно будет ввести снова
   - История чатов сохраняется

3. **Не делитесь своим ключом**
   - Это личный секретный ключ
   - Не публикуйте его в скриншотах или коде

## ❓ Частые вопросы

### ❓ Нужно ли вводить ключ каждый раз?

**Да.** Это сделано для безопасности. Ключ не сохраняется между сессиями.

### ❓ Можно ли использовать .env файл как раньше?

**Да!** Обратная совместимость сохранена. Если у вас есть `.env` с ключом, можно создать `ChatManager()` без параметров в коде.

### ❓ Что если я забуду ключ?

Просто получите новый ключ на https://platform.openai.com/api-keys

### ❓ Безопасно ли это?

**Да!** Ключ хранится только в памяти браузера и автоматически удаляется при закрытии.

### ❓ Работает ли это на мобильных?

**Да!** Streamlit адаптируется под любой экран.
