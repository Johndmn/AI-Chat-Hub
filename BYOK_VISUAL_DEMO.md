## 🎬 Сценарий использования (пошагово)

### Сценарий 1: Первый запуск

**Шаг 1:** Пользователь открывает приложение

```
→ Видит предупреждение: "⚠️ API ключ не введён"
→ Видит инструкцию с ссылкой на platform.openai.com
```

**Шаг 2:** Открывает expander "🔑 Настройки API"

```
→ Видит поле для ввода ключа
→ Видит кнопку "💾 Сохранить ключ"
```

**Шаг 3:** Вставляет API ключ

```
→ Вводит: sk-proj-abc123...
→ Нажимает "💾 Сохранить ключ"
```

**Шаг 4:** Видит подтверждение

```
→ Зелёное уведомление: "✅ Ключ сохранён. Можно работать."
→ Появляется кнопка "🗑️ Очистить ключ"
```

**Шаг 5:** Настраивает параметры

```
→ Выбирает модель: gpt-4o-mini
→ Устанавливает температуру: 0.7
→ Видит: "Текущие настройки: gpt-4o-mini, температура 0.7"
```

**Шаг 6:** Отправляет первый запрос

```
→ Вводит: "Объясни, что такое Python"
→ Нажимает Enter
→ Видит индикатор: "🤖 Печатает..."
→ Получает ответ с временной меткой
```

---

### Сценарий 2: Работа с несколькими чатами

**Шаг 1:** Создание нового чата

```
→ Нажимает "🆕 Новый чат"
→ Автоматически создаётся "Новый чат 2"
→ Переключается на новый чат
```

**Шаг 2:** Работа в новом чате

```
→ Вводит: "Напиши функцию сортировки"
→ Получает ответ
→ Видит счётчик: "💬 Новый чат 2 (2)"
```

**Шаг 3:** Переключение между чатами

```
→ Нажимает на "💬 Новый чат 1 (2)"
→ Видит историю первого чата
→ Может продолжить диалог
```

**Шаг 4:** Удаление чата

```
→ Нажимает 🗑️ рядом с "Новый чат 3"
→ Видит модальное окно: "⚠️ Удалить чат...?"
→ Нажимает "✅ Да"
→ Чат удаляется, появляется: "✅ Чат удалён"
```

---

### Сценарий 3: Сравнение моделей

**Шаг 1:** Тест с gpt-3.5-turbo

```
→ Выбирает модель: gpt-3.5-turbo
→ Задаёт: "Напиши стихотворение"
→ Получает простое стихотворение
→ Время ответа: ~2 секунды
```

**Шаг 2:** Тест с gpt-4o-mini

```
→ Создаёт новый чат
→ Выбирает модель: gpt-4o-mini
→ Задаёт: "Напиши стихотворение"
→ Получает более качественное стихотворение
→ Время ответа: ~3 секунды
```

**Шаг 3:** Тест с gpt-4o

```
→ Создаёт новый чат
→ Выбирает модель: gpt-4o
→ Задаёт: "Напиши стихотворение"
→ Получает профессиональное стихотворение
→ Время ответа: ~4 секунды
```

**Результат:** Пользователь видит разницу в качестве и скорости.

---

### Сценарий 4: Экспериментирование с температурой

**Низкая температура (0.2):**

```
Запрос: "Какая столица Франции?"
Ответ: "Столица Франции — Париж."
→ Краткий, точный ответ
```

**Средняя температура (0.7):**

```
Запрос: "Расскажи о Париже"
Ответ: "Париж — столица и крупнейший город Франции..."
→ Сбалансированный, информативный ответ
```

**Высокая температура (1.0):**

```
Запрос: "Напиши рассказ о Париже"
Ответ: "Солнечные лучи пробивались сквозь утренний туман..."
→ Креативный, художественный текст
```

## 🎭 Анимации

### 1. Индикатор "Печатает..."

```
Итерация 1: "🤖 Печатает."
Итерация 2: "🤖 Печатает.."

```

```

```
Кнопки:     #2D2D2D → #3D3D3D (светлеют)
