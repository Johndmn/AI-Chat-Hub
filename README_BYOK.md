## 📋 Описание

**AI Tutor BYOK** - это минималистичное Streamlit-приложение для общения с моделями OpenAI GPT. Ключевая особенность - вы используете **свой собственный API ключ**, который хранится только в памяти сессии и никогда не записывается на диск.

### 🎯 Основные возможности

✅ **Безопасное хранение API ключа** - только в `st.session_state`  
✅ **Выбор модели** - gpt-4o, gpt-4-turbo, gpt-4o-mini, gpt-3.5-turbo  
✅ **Настройка температуры** - от 0.0 до 1.0 (контроль креативности)  
✅ **Управление чатами** - создание, переключение, удаление  
✅ **Тёмная тема** - минималистичный дизайн для комфортной работы  
✅ **Временные метки** - отслеживание времени сообщений  
✅ **Индикатор печати** - анимированное "🤖 Печатает..."

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install streamlit openai
```

### 2. Запуск приложения

```bash
streamlit run app_byok.py
```

### 3. Настройка и использование

1. Откройте приложение в браузере (http://localhost:8501)
2. Введите свой OpenAI API ключ в разделе "🔑 Настройки API"
3. Нажмите "💾 Сохранить ключ"
4. Начните общение с AI!

## 🔐 Безопасность

### ✅ Что реализовано

- API ключ хранится **только в st.session_state**
- Ключ **не записывается** в файлы, логи или базы данных
- Поле ввода имеет тип `password` (символы скрыты)
- Ключ **автоматически удаляется** при закрытии браузера

### ⚠️ Важные правила

1. **Не используйте** на общедоступных компьютерах
2. **Очищайте ключ** после работы кнопкой "🗑️ Очистить ключ"
3. **Не публикуйте** скриншоты с видимым ключом
4. **Регулярно обновляйте** API ключи на platform.openai.com

## 🛠️ Технические детали

### Структура кода

```python
app_byok.py
├── init_session_state()          # Инициализация переменных состояния
├── create_new_chat()              # Создание нового чата
├── switch_chat()                  # Переключение между чатами
├── delete_chat()                  # Удаление чата
├── get_current_chat()             # Получение активного чата
├── add_message()                  # Добавление сообщения в историю
├── call_openai_api()              # Вызов OpenAI API
├── display_message()              # Отображение сообщения с timestamp
├── show_typing_indicator()        # Анимация "Печатает..."
└── main()                         # Главная функция
```

### Переменные состояния

```python
st.session_state = {
    "api_key": str,                # OpenAI API ключ
    "model": str,                  # Выбранная модель
    "temperature": float,          # Температура (0.0-1.0)
    "chats": Dict[str, Dict],      # Все чаты
    "current_chat_id": str,        # ID активного чата
    "chat_counter": int,           # Счётчик для названий
}
```

### Структура чата

```python

    "history": List[Dict],         # История сообщений
    "created_at": datetime,        # Время создания
```

## ❓ FAQ

<details>
<summary><b>Где хранится мой API ключ?</b></summary>

Только в памяти браузера (`st.session_state`). Не записывается в файлы, не отправляется на сервер, удаляется при закрытии вкладки.

</details>

<details>
<summary><b>Нужно ли вводить ключ каждый раз?</b></summary>

Да. Это сделано для безопасности. Ключ не сохраняется между сессиями.

</details>

<details>
<summary><b>Сколько это стоит?</b></summary>

Зависит от модели и объёма использования. Средний диалог: $0.01-0.10. Проверить расходы можно на https://platform.openai.com/usage

</details>

<details>
<summary><b>Безопасно ли это?</b></summary>

Да, при соблюдении правил:

- Используйте на личном компьютере
- Очищайте ключ после работы
- Не публикуйте скриншоты с ключом
</details>

<details>
<summary><b>Можно ли сохранить чат?</b></summary>

В текущей версии нет. Чаты хранятся только в памяти и удаляются при закрытии браузера. Экспорт/импорт планируется в будущих версиях.

</details>

## 🐛 Устранение проблем

### Проблема: "⚠️ API ключ не введён"

**Решение:** Введите API ключ в разделе "🔑 Настройки API" и нажмите "💾 Сохранить ключ"

### Проблема: "❌ Ошибка при вызове API"

**Возможные причины:**

- Неверный API ключ (проверьте на platform.openai.com)
- Исчерпан баланс (пополните счёт)
- Нет доступа к модели (попробуйте gpt-3.5-turbo)
- Проблемы с сетью (проверьте интернет)

### Проблема: Приложение не запускается

**Решение:**

```bash
pip install --upgrade streamlit openai
streamlit run app_byok.py
```
