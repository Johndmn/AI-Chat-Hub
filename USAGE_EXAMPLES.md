# 🎬 Примеры использования новых UX-функций

## 📖 Руководство по тестированию

---

## Сценарий 1: Базовый чат с UX-улучшениями

### Шаг 1: Запуск приложения

```bash
streamlit run app.py
```

### Шаг 2: Обратите внимание на счётчик токенов

- В верхней части страницы увидите панель: **🔢 Токены в текущем чате: 0**
- Это начальное состояние пустого чата

### Шаг 3: Отправьте первое сообщение

**Введите:** "Привет! Как дела?"

**Что произойдёт:**

1. Ваше сообщение появится с временной меткой справа (например: `14:25:15`)
2. Сразу после этого увидите: **🤖 Печатает...** (с анимацией точек)
3. Через 1-3 секунды анимация исчезнет
4. Появится ответ AI с временной меткой (например: `14:25:18`)
5. Счётчик токенов обновится (например: **🔢 Токены в текущем чате: 87**)

## Сценарий 2: Использование быстрых промптов

### Шаг 1: Откройте быстрые промпты в боковой панели

- Найдите раздел **"Быстрые промпты"**
- Увидите три кнопки: ✍️, 🔍, 📝

### Шаг 2: Нажмите на кнопку "Объяснить код" (🔍)

**Что произойдёт:**

- Появится текстовое поле с шаблоном:
  ```
  Объясни следующий код:
  ```
  [вставь код здесь]
  ```

  ```

### Шаг 3: Отредактируйте и отправьте

**Измените на:**

```
Объясни следующий код:
```

def hello():
print("Hello, World!")

```

```

**Что произойдёт:**

1. Ваше сообщение отобразится с временной меткой
2. Индикатор **🤖 Печатает...** покажет анимацию
3. AI ответит с объяснением кода
4. Счётчик токенов увеличится (учитывая код в промпте)

## Сценарий 4: Работа с правилами общения

### Шаг 1: Установите правила

В разделе **"Правила общения"** введите:

```
- Отвечай кратко (максимум 2 предложения)
- Используй эмодзи для дружелюбности
```

### Шаг 2: Отправьте сообщение

**Введите:** "Что такое Python?"

**Результат:**

1. Индикатор **🤖 Печатает...** покажет анимацию
2. AI ответит коротко и с эмодзи:
   > Python 🐍 — это мощный язык программирования, популярный благодаря простоте синтаксиса. Отлично подходит для новичков и профессионалов! 🚀
3. Временная метка покажет время ответа
4. Токены учтут и правила, и ответ

## Сценарий 6: Переключение между чатами

### Шаг 1: Создайте новый чат

- Нажмите **🆕 Новый чат**

### Шаг 2: Отправьте сообщение в новом чате

**Введите:** "Тестовое сообщение"

**Наблюдение:**

- Счётчик токенов сбросится на начальное значение
- Временные метки начнутся с нуля
- Каждый чат имеет свой независимый счётчик

### Шаг 3: Вернитесь к первому чату

- Выберите предыдущий чат из списка

**Наблюдение:**

- Счётчик токенов восстановится к предыдущему значению
- Все временные метки остались на месте
- История сохранена полностью

## Сценарий 7: Экспорт чата с метаданными

### Шаг 1: Заполните чат сообщениями

Отправьте 3-5 сообщений с ответами AI

### Шаг 2: Экспортируйте чат

- В боковой панели найдите раздел **"Экспорт"**
- Нажмите **📥 Скачать чат**

### Шаг 3: Откройте скачанный файл

**Содержимое:**

```
User: Привет!

AI: Привет! Как дела?

User: Расскажи о Python

AI: Python — это язык программирования...

```

**Примечание:** Экспорт пока не включает временные метки, но их легко добавить в будущем!

## Сценарий 8: Стресс-тест (много токенов)

### Отправьте очень длинный запрос:

```
Напиши подробное эссе на тему "Искусственный интеллект в медицине"
с разделами:
1. История развития
2. Современные применения
3. Будущие перспективы
4. Этические вопросы
```

**Результат:**

1. Индикатор **🤖 Печатает...** будет показываться дольше (5-10 секунд)
2. AI сгенерирует длинный ответ
3. Счётчик токенов резко увеличится (например, с 100 до 2500+)
4. Временная метка покажет длительность генерации

## 🐛 Возможные проблемы и решения

### Проблема 1: Индикатор не исчезает

**Причина:** Медленное API или ошибка сети  
**Решение:** Подождите или обновите страницу (F5)

### Проблема 2: Счётчик показывает 0

**Причина:** Чат пустой или только что создан  
**Решение:** Отправьте первое сообщение — счётчик обновится

### Проблема 3: Временные метки одинаковые

**Причина:** Сообщения отправлены в одну секунду  
**Решение:** Это нормально! Точность — до секунды

### Проблема 4: Ошибка tiktoken

**Причина:** Библиотека не установлена  
**Решение:**

```bash
pip install tiktoken
```
