# UX-улучшения для AI Tutor Chat

## Описание добавленных функций

В Streamlit-приложение были интегрированы следующие UX-улучшения для повышения удобства использования:

---

## 1. 🤖 Индикатор "Печатает..."

**Функция:** `show_typing_indicator(placeholder, duration)`

### Что делает:

- Отображает анимированный индикатор "🤖 Печатает..." с пульсирующими точками (".", "..", "...")
- Показывается перед тем, как модель начинает генерировать ответ
- Автоматически исчезает, когда ответ полностью сгенерирован

### Как работает:

```python
# Создаём placeholder для анимации
typing_placeholder = st.empty()

# Показываем индикатор
with typing_placeholder.container():
    show_typing_indicator(typing_placeholder, duration=1.5)

# После получения ответа очищаем индикатор
typing_placeholder.empty()
```

### Где используется:

- В обычном режиме ввода сообщений (через `st.chat_input`)
- В режиме редактирования быстрых промптов (когда пользователь использует шаблоны)

## 2. ⏰ Временные метки сообщений

**Функция:** `format_timestamp(dt)` и отображение через HTML

### Что делает:

- Под каждым сообщением отображается время в формате `HH:MM:SS`
- Метка показывается мелким серым текстом с выравниванием по правому краю
- Применяется как к сообщениям пользователя, так и к ответам AI

### Как работает:

```python
# Получаем текущее время
timestamp = format_timestamp()

# Отображаем временную метку
st.markdown(
    f"<div style='font-size:0.75em; color:#999; "
    f"text-align:right; margin-top:-10px;'>{timestamp}</div>",
    unsafe_allow_html=True,
)
```

### Где используется:

- В истории чата (для всех загруженных сообщений)
- При отправке новых сообщений (пользователь и AI)

## 3. 🔢 Счётчик токенов

**Функции:**

- `count_tokens(text, model)` — подсчитывает токены в тексте
- `calculate_total_tokens(chat_history, model)` — суммирует токены всего чата

### Что делает:

- Отображает общее количество токенов в текущем чате
- Показывается в верхней части интерфейса с красивым оформлением
- Использует библиотеку `tiktoken` для точного подсчёта токенов
- Автоматически обновляется при каждом новом сообщении

### Как работает:

```python
# Подсчитываем токены для текущей истории чата
total_tokens = calculate_total_tokens(chat_history, model_name)

# Сохраняем в session_state
st.session_state.total_tokens = total_tokens

# Отображаем красиво оформленный счётчик
st.markdown(
    f"<div style='text-align:center; color:#666; font-size:0.9em; "
    f"padding:10px; background-color:#f0f2f6; border-radius:5px; "
    f"margin-bottom:15px;'>"
    f"🔢 <b>Токены в текущем чате:</b> {st.session_state.total_tokens}"
    f"</div>",
    unsafe_allow_html=True,
)
```

### Особенности:

- Поддерживает различные модели GPT (автоматически выбирает подходящий токенизатор)
- При ошибке использует токенизатор `cl100k_base` (GPT-4/3.5)
- Подсчитывает токены для всех сообщений в истории чата
