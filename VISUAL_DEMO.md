**Анимация при генерации ответа:**

```

│  🤖 Assistant                                │

┌─────────────────────────────────────────────┐

Шаг 3 (0.6с):

После завершения:
┌─────────────────────────────────────────────┐
```

- Показывается сразу после отправки сообщения
- Пульсирующие точки создают эффект "живой" печати
- Автоматически исчезает, когда ответ готов

## 🚀 Как протестировать

1. **Запустите приложение:**

   ```bash
   streamlit run app.py
   ```

2. **Проверьте счётчик токенов:**

   - Посмотрите на верхнюю панель — там должно быть число токенов
   - Отправьте сообщение — счётчик увеличится

3. **Проверьте индикатор "Печатает...":**

   - Напишите любое сообщение
   - Сразу после отправки увидите "🤖 Печатает..." с анимацией
   - Индикатор исчезнет, когда придёт ответ

4. **Проверьте временные метки:**
   - Посмотрите справа внизу каждого сообщения
   - Там должно быть время в формате HH:MM:SS серым цветом
